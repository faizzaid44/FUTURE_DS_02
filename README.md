# FUTURE_DS_02
FUTURE_DS_02 — Customer Churn Analysis
This project analyzes customer subscription data to identify churn patterns, understand retention drivers, and recommend strategies to reduce customer loss.
Project objectives
- Calculate customer churn and retention rates.
- Identify customer segments with higher churn.
- Analyze tenure, contracts, and payment methods.
- Recommend practical retention strategies.
Tools used: Excel, Python, CSV
Deliverables
- Customer churn dashboard
- Analysis report
- Cleaned dataset
Key finding: 26.54% of customers in the dataset have churned.
